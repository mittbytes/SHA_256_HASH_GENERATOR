# SHA-256_HASH-GENERATOR

## About
A simple Python project that generates the SHA-256 hash of a file.

## Features
- Takes a filename as input.
- Reads the file in binary mode.
- Generates and displays the SHA-256 hash.

## Concepts Used
- Python `hashlib` module
- File handling
- Binary mode
- User input

## What I Learned
I learned how to use SHA-256 to generate a unique hash value for file data.

Beginner Python project.
